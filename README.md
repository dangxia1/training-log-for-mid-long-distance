# 训练日志

## 项目简介
一款用于记录日常训练（健身、跑步、技能练习等）的本地单页应用。数据存储在浏览器 localStorage，无需服务器，打开即用。

---

## 启动

根目录下有 `运行训练日志.bat`，右键 → 发送到桌面快捷方式，双击即可打开。

> 首次使用需先运行 `npm install`。

---

## 界面总览

顶部刊头导航 + 内容区 max-width 1100px 居中。

```
 ┌──────────────────────────────────────────────────┐
 │ 训练日志 Training Journal  [计划][思路][笔记][类型] [⚙][◐] │
 ├──────────────────────────────────────────────────┤
 │                                                  │
 │             当前选中视图（编辑网格居中）            │
 │                                                  │
 │                                        [+] FAB  │
 └──────────────────────────────────────────────────┘
```

- **计划**：双模式（杂志跨页日历 / 滚动锚点计划窗），衬线标题，7 列网格
- **思路**：周表格 + 左侧文件树（Markdown 文档管理，编辑/预览）
- **笔记**：Markdown 编辑器，编辑/预览切换，自动保存
- **类型**：左侧标签目录 + 右侧编辑风记录卡片 + Star 筛选

---

## 标签层级

用 `·`（中文间隔号）分隔层级：

```
强度课           ← 父标签（先创建）
强度课·专项      ← 子标签
强度课·I
强度课·R
力量训练·下肢
```

- 侧栏自动按层级缩进，父标签左侧 `▸` 箭头展开/折叠。
- 点击父标签时右侧汇总父标签及所有子标签记录。
- 悬停标签行出现垃圾桶图标，点击删除。

---

## 日常操作

1. **新增训练**：底部"+ 新增训练记录"，填写内容、感受、日期，勾选或新建标签。
2. **浏览记录**："训练类型"标签页选择标签查看；或"周视图"按日历浏览。
3. **编辑/删除**：周视图点击卡片编辑，训练类型视图中每条记录右侧有编辑/删除按钮。
4. **Star 筛选**：标签视图顶部开关，只看高质量训练。
5. **数据备份**："数据"→"导出数据"，下载 JSON 备份。

---

## 数据导入

根目录 `训练.md` 为权威数据源，运行 `node parse-training.js` 生成 `训练数据导入.json`，再通过"数据"→"导入数据"加载。

> 导入会覆盖当前数据，建议先导出备份。

---

## 视觉设计

杂志/编辑风格（taste-skill 规范），设计要点：

- **刊头导航**：顶部固定导航栏（毛玻璃效果），替代传统侧栏
- **编辑排版**：Playfair Display + Noto Serif SC 衬线标题，Inter 正文，编辑级字体层级
- **暖纸配色**：底色 `#faf8f3`（暖白纸色），墨色正文，酒红单点缀 (`#8b3a3a`)
- **深色模式**：一键切换，墨底浅字，完整适配
- **杂志跨页日历**：7 列网格日历，衬线日期数字，悬停交互
- **编辑风卡片**：衬线斜体日期 + 引文体感受 + 细线分割
- **SVG 图标**：内联 SVG 替代所有 emoji
- **微噪点纹理**：全局叠加打破数字平面感

## 技术栈
- Vue 3（Composition API）+ Pinia + Vite
- 数据持久化：localStorage
- Express 后端（/docs 文件操作）

## 开发

```bash
npm install
npm run dev         # Vite 开发服务器 localhost:5173
npm run dev:server  # Express 后端 localhost:3001
npm run dev:all     # 同时启动前后端
npm run build       # 构建到 dist/
```
