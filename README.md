# 训练日志

一款用于记录日常训练（健身、跑步、技能练习等）的本地单页应用。数据存储在浏览器 localStorage，Express 后端提供 `/docs` 文件读写。

---

## 启动

```bash
npm install
npm run dev:all     # 同时启动前端 (5173) 和后端 (3001)
```

或者双击 `运行训练日志.bat`（可发送桌面快捷方式）。

---

## 界面

```
 ┌─────────────────────────────────────────────────┐
 │ 训练日志 Training Journal    [计划] [思路] [类型]  [⚙][◐] │
 ├─────────────────────────────────────────────────┤
 │                                                 │
 │            当前视图（max-width 1100px 居中）      │
 │                                                 │
 │                                       [+] FAB  │
 └─────────────────────────────────────────────────┘
```

- **计划**：周历 / 计划双模式，7 行纵向排列，每行 日头│星标│标签│内容 四列对齐，内容保留换行
- **思路**：周表格 + 左侧文件树，Markdown 编辑/预览
- **类型**：标签目录 + 记录卡片 + Star 筛选

---

## 标签层级

用 `·`（中文间隔号）分隔层级：

```
力量训练·下肢
力量训练·上肢
强度课·I
强度课·R
```

- 自动按层级缩进，`▸` 展开/折叠
- 点击父标签汇总所有子标签记录
- 双击标签名可重命名

---

## 日常操作

1. **新增训练**：右下角 `+` 按钮
2. **浏览**：计划页按日历查看，类型页按标签筛选
3. **Star 筛选**：只看高质量训练
4. **数据备份**：顶栏 ⚙ → 导出 JSON

---

## 设计

杂志编辑风格，taste-skill 规范：

- Playfair Display + Noto Serif SC 衬线标题，Inter 正文
- 暖纸底色 + 酒红点缀 + 深色模式
- 内联 SVG 图标，全局微噪点纹理

## 技术栈

Vue 3 + Pinia + Vite，localStorage 持久化，Express 后端

## 开发

```bash
npm install
npm run dev         # localhost:5173
npm run dev:server  # localhost:3001
npm run dev:all     # 前后端同时启动
npm run build       # 构建到 dist/
```
